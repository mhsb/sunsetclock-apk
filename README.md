# ساعت غروب‌کوک (Sunset Clock) — اپ اندروید

اپ ساعت اندرویدی با Kotlin و Jetpack Compose. ساعت اصلی آن «ساعت غروب‌کوک» است: ساعت ۰ لحظه‌ی غروب آفتاب است و فاصله‌ی دو غروب پیاپی به ۲۴ ساعت مساوی تقسیم می‌شود (۱ = یک ساعت بعد از غروب، ۲۳ = حدود یک ساعت مانده به غروب).

ساخته‌شده توسط حسین شیبه — [sheibah.ir](https://sheibah.ir)

## قابلیت‌ها

- **ساعت غروب‌کوک** با صفحه‌ی ۲۴ ساعته (بالا = غروب)، کمان شب و روز، نقطه‌ی اذان‌ها و خورشیدِ لحظه‌ی اکنون
- ساعت عادی، تاریخ شمسی و قمری با برچسب «شب/روز + نام روز هفته» (روز از غروب شروع می‌شود؛ مثلاً «شب جمعه»)
- نوار پیشرفت «شب سپری‌شده» و «روز باقی‌مانده»، شمارش معکوس تا اذان بعدی، فهرست اوقات امروز
- **اوقات شرعی** بدون نیاز به اینترنت؛ روش‌ها: مؤسسه ژئوفیزیک دانشگاه تهران (پیش‌فرض)، لوا (قم)، MWL، ISNA، مصر، ام‌القری، کراچی
- **هشدار**: ساعت معمولی یا **نسبت به اذان/رویداد** (مثلاً «۴۵ دقیقه قبل از اذان صبح»، «۳۰ دقیقه بعد از غروب»)، تکرار در روزهای دلخواه، تعویق ۱۰ دقیقه‌ای، صفحه‌ی تمام‌صفحه روی قفل
- کرنومتر با ثبت دور، تایمر شمارش معکوس (در پس‌زمینه هم زنگ می‌خورد)
- مکان: فهرست شهرها (پیش‌فرض تهران) یا موقعیت تقریبی GPS (بدون Google Play Services)
- فارسی (پیش‌فرض، ارقام فارسی) و انگلیسی، پوسته‌ی روشن/تیره/سیستم، تعدیل تاریخ قمری ±۲ روز

## ساخت APK بدون لپ‌تاپ (با گیت‌هاب)

1. در گیت‌هاب یک مخزن (repository) جدید بسازید.
2. محتوای همین پوشه را (همه‌ی فایل‌ها، از جمله پوشه‌ی مخفی `.github`) آپلود کنید.
   - اگر از مرورگر گوشی آپلود می‌کنید و پوشه‌ی `.github` را نمی‌پذیرد، فایل `.github/workflows/build.yml` را با گزینه‌ی *Add file ← Create new file* و با همین مسیر دستی بسازید و محتوایش را کپی کنید.
3. به تب **Actions** بروید؛ workflow با نام **Build APK** خودکار اجرا می‌شود (یا Run workflow را بزنید).
4. بعد از چند دقیقه، داخل همان اجرا در بخش **Artifacts** فایل `SunsetClock-debug-apk` را دانلود و از حالت zip خارج کنید و `app-debug.apk` را نصب کنید.

## ساخت با Android Studio

پوشه را باز کنید، Sync کنید و Run بزنید (نیاز به JDK 17 و Android SDK 35). یا در ترمینال: `./gradlew assembleDebug`.

## ساختار پروژه

```
app/src/main/java/ir/sheibah/sunsetclock/
  astro/    PrayerTimes.kt (اوقات)، Calendars.kt (شمسی/قمری)
  core/     Cities.kt، ClockCalc.kt (وضعیت ساعت غروب‌کوک)، AlarmItem.kt (مدل و محاسبه‌ی زمان هشدار)
  data/     SettingsRepo، AlarmStore، TimerStore، LocationHelper
  alarm/    AlarmScheduler، AlarmReceiver، AlarmService، AlarmActivity، BootReceiver
  ui/       صفحه‌ها (Compose) و تم
  MainActivity.kt، MainViewModel.kt، SunsetClockApp.kt
```

بسته‌های `astro` و `core` به اندروید وابسته نیستند و جداگانه قابل تست‌اند.

## نکات فنی و محدودیت‌ها

- هشدارها با `AlarmManager.setAlarmClock` ثبت می‌شوند (دقیق، مستقل از Doze و بدون نیاز به مجوز «آلارم دقیق»). برای هشدارهای نسبت‌به‌اذان، زمان هر نوبت پس از زنگ خوردن و نیز هنگام باز شدن اپ، بوت و تغییر ساعت/منطقه‌ی زمانی دوباره محاسبه می‌شود.
- روی برخی گوشی‌ها (شیائومی، سامسونگ، هوآوی و ...) باید اپ از «بهینه‌سازی باتری / محدودیت پس‌زمینه» مستثنا شود؛ در **تنظیمات اپ ← اطمینان از زنگ خوردن هشدارها** میان‌بر هست. در اندروید ۱۴ به بالا اجازه‌ی «نمایش روی صفحه‌ی قفل» (Full-screen intent) را هم بررسی کنید.
- دقت اوقات شرعی حدود ±۱ دقیقه است (الگوریتم PrayTimes). برای عرض‌های جغرافیایی خیلی بالا که زاویه‌ها تعریف نمی‌شوند، مقدار پشتیبان تقریبی استفاده می‌شود.
- تاریخ شمسی با الگوریتم ۳۳ ساله حساب می‌شود (برای سال‌های جاری درست است) و تاریخ قمری ام‌القری است؛ اگر با رؤیت هلال محل شما فرق داشت، تعدیل ±۱ روز را تنظیم کنید.
- کرنومتر فقط تا زنده بودن پردازش اپ ذخیره می‌ماند؛ تایمر و هشدارها پایدارند.
- خروجی workflow، APK **دیباگ** است. برای انتشار در بازار نسخه‌ی امضاشده‌ی release لازم است.
